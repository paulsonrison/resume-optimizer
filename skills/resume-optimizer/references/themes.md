# Resume visual themes

Color and typography do not prove ATS compatibility. Use a white background and actual text in a single linear column throughout. Dates stay in the same reading sequence as their roles; avoid layout tables even for alignment.

## Default alignment and spacing

Center the name, professional title, and contact lines. Left-align all remaining content. Put a thin full-width divider beneath each section heading, with about 4 pt clearance before the following text. Do not place decorative rules beneath the candidate's name.

For Classic Executive Slate, use 10 pt body text with 13 pt line spacing (1.3), 3 pt after bullets, 2 pt after ordinary paragraphs, 5 pt before a new role/project, and 8 pt before a section heading. Use about 23 pt leading for the 18 pt name. Match these values in PDF and Word, allowing minor renderer-specific adjustments after visual inspection. Section divider: 0.6 pt, muted slate #94A3B8; in Word use a native paragraph bottom border with roughly 3 pt separation.

These are starting values, not a reason to create overflow. Preserve legibility and all required entries; shorten repetition before tightening spacing. Other themes inherit this alignment and spacing unless their explicit values or the user's instructions override them. Verify summary length, page count, and text extraction after changing spacing.

| 4. High-Density One-Page Compact | Slate palette unless user chooses otherwise | Body 9–9.5 pt; line spacing 1.28–1.32; 10 mm top/bottom margins; compact education lines |

Use installed fonts and disclose substitutions. Begin at the larger size in each range; do not shrink below 9 pt to force a page. Confirm page size for a known application requirement; otherwise choose A4 or Letter appropriate to the supplied context and state the choice. Render and re-count after each layout change. If the compact theme still overflows, resolve content priorities with the user rather than silently deleting entries.
